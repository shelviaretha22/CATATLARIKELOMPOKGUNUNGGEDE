# CatatLari 🏃

Aplikasi mobile sederhana berbasis Flutter untuk mencatat aktivitas lari harian pengguna.  
Aplikasi ini dibuat sebagai tugas praktikum Pemrograman Mobile dengan menerapkan arsitektur MVVM (Model View ViewModel).

## 📱 Deskripsi Aplikasi

CatatLari merupakan aplikasi pencatatan aktivitas lari yang membantu pengguna untuk menyimpan riwayat lari, melihat rata-rata jarak tempuh, serta mengelola data aktivitas olahraga dengan tampilan modern dan sederhana.

Aplikasi ini dikembangkan menggunakan Flutter dan menerapkan pattern MVVM menggunakan Provider sebagai state management.
